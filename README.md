A two-tier pump.fun paper-trading bot for the replay harness: a strict momentum tier buys coins that survived the opening dump and are rising on real buy flow, while a small-stake breadth tier keeps the run diversified across many coins. Fast take-profits, tight stops, and a trailing stop; paper trading only, no real funds.

## Run it

```sh
node main.ts
```
